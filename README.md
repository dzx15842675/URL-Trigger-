# 扩展管家（Extension Manager）- Edge 浏览器扩展智能管理工具

扩展管家是一款 Edge 浏览器扩展，帮助您通过分组机制一键管理所有扩展，支持批量启停、URL 规则自动切换与启动时自动清理，让浏览器始终保持轻快高效。

## 功能特性

- **分组管理** - 创建多个普通分组，不同场景一键切换，每组独立锁定扩展列表
- **一键启停** - 点击即可启用或禁用单个扩展，告别手动逐个操作
- **批量切换** - 切换分组时自动启用当前分组扩展、关闭其余扩展
- **固定分组** - 设置全局常驻扩展，不受任何分组切换影响
- **URL 规则引擎** - 访问特定网址时自动启用/禁用对应扩展
- **启动自动清理** - Edge 重启时自动检测并关闭普通分组外多余启用的扩展
- **分组切换清理** - 每次手动切换普通分组时同步清理临时手动开启的扩展
- **多语言支持** - 内置中英日韩俄等多语言界面
- **暗色主题** - 现代暗色 UI，与 Edge 原生风格一致

## 快速开始

### 安装

1. 下载最新版本 [扩展管家(Extension Manager).zip]()
2. 解压到本地目录
3. 打开 Edge 浏览器，地址栏输入 `edge://extensions/`
4. 打开左下角「开发人员模式」开关
5. 点击「加载解压缩的扩展」，选择解压后的目录

### 使用

1. 点击工具栏中的扩展管家图标打开弹窗
2. 首次使用会自动创建默认分组
3. 在弹窗中点击扩展旁的开关即可启用/禁用
4. 点击分组名可切换分组，扩展状态自动同步
5. 右键扩展可将其锁定到当前分组
6. 点击「设置」进入完整管理页面，配置分组与 URL 规则

## 常见问题

**Q: 切换分组后有些扩展没被关闭？**
A: 检查该扩展是否被设置为「固定分组」，固定分组中的扩展不受分组切换影响。

**Q: 弹出窗口白屏？**
A: 请确保使用 Edge 浏览器并以「加载解压缩的扩展」方式安装，不要直接拖入 CRX 文件。

**Q: 启动后扩展没有自动清理？**
A: 自动清理仅针对当前活动普通分组 lock 之外的扩展，固定分组和 URL 规则中的扩展不受影响。
